# PawConnect

**PawConnect** is a React-based pet adoption and animal welfare platform connecting prospective adopters, shelters, and animal welfare communities.

## Features

- Pet discovery and behaviour-based adoption matching
- Adoption applications and shelter directory
- Rescue requests and animal welfare support
- Community stories, reviews, and donations
- Responsive interface with interactive components

## Tech Stack

**Frontend:** React, JavaScript, HTML, CSS  
**Build Tool:** Vite  
**Routing:** React Router  
**Version Control:** Git, GitHub

## Getting Started

```bash
git clone https://github.com/Reva-Shukla/PawConnect.git
cd PawConnect
npm install
npm run dev
```
